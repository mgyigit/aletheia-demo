# Torug Haber Doğrulama (demo)

The public desk of Torug Haber Doğrulama, a multi-agent misinformation analysis system.
Open it at **https://mgyigit.github.io/aletheia-demo/**.

- **Arşiv** shows 24 example analyses (real social-media claims and one news article read from its link); they open without any server.
- Analyses never use fact-checking organisations (AA Teyit Hattı, Teyit, Doğruluk Payı, AFP, Reuters, …) as evidence:
  every verdict is the system's own, reached from primary sources.
- **Live analyses** run on the shared analysis server (a Hugging Face Space), or on one you run yourself, chosen under
  *Kurulum / Setup*, with your own API keys. Keys stay in your browser and go only to that server.

This repository holds only the built web page; the analysis code is not published.
