# Aletheia · verification desk (demo)

The public desk of Aletheia, a multi-agent misinformation analysis system.
Open it at **https://mgyigit.github.io/aletheia-demo/**.

- **Arşiv** shows 23 example analyses of real social-media claims; they open without any server.
- Analyses never use fact-checking organisations (AA Teyit Hattı, Teyit, Doğruluk Payı, AFP, Reuters, …) as evidence:
  every verdict is the system's own, reached from primary sources.
- **Live analyses** run on a backend you choose under *Ayarlar / Settings* (your own computer, or another address),
  with your own API keys. Keys stay in your browser and go only to that backend.

This repository holds only the built web page; the analysis code is not published.
